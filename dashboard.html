Rule-Based Heuristics

Scores wallets using 7 hand-crafted rules based on known money-laundering typologies. Fast, fully deterministic, easy to audit — but can only catch patterns that were explicitly programmed in. Blind to novel sequences.

Bidirectional LSTM

Reads each wallet's full transaction history as a time series. Learns temporal patterns — value rhythms, timing gaps, counterparty diversity over time. Trained on pseudo-labels from the rule scorer, then generalises beyond them. Attention weights show exactly which transactions drove the score.

How to read disagreements

LSTM scores higher

The model found a suspicious temporal pattern (timing rhythm, value cycle, automated behaviour) that the fixed rules don't cover. Worth a manual review even if rules say clean.

Rules score higher

A specific rule fired (e.g. fan-out >10, night activity >40%) but the LSTM saw no unusual temporal structure overall. Could be a rule false-positive — or a LSTM blind spot.

Both agree: CLEAN

Strong signal of low risk. Neither explicit heuristics nor learned temporal patterns raised flags. High confidence the wallet is not engaged in layering.
